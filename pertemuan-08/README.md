# Pengembangan Peminjaman Fasilitas Kampus

## 1. Fitur yang dibuat
- Menu navigasi Peminjaman Fasilitas.
- Formulir Permohonan Peminjaman Fasilitas Kampus.
- Pilihan Ruang Kelas, Aula,
  Laboratorium Komputer, dan Proyektor.
- Input nama, tanggal, durasi, dan keperluan.
- Tombol Kirim dan Batal.

## 2. Pemrosesan Data
- Menggunakan metode POST dan PHP.
- Validasi JavaScript dan PHP.
- Normalisasi masukan.
- Session untuk menyimpan hasil sementara.
- htmlspecialchars() untuk keamanan output.
- Pola Post-Redirect-Get (PRG).
- Menampilkan hasil peminjaman.

## 3. Pengujian
Catat hasil pengujian sebenarnya:

| Pengujian | Hasil |
|---|---|
| Menu navigasi | Belum diuji |
| Formulir | Belum diuji |
| Pengiriman data | Belum diuji |
| Validasi | Belum diuji |
| PRG | Belum diuji |
| Formulir Kontak lama | Belum diuji |

Ganti status setelah pengujian dilakukan.

## 4. Catatan
Data peminjaman disimpan sementara
menggunakan session, belum menggunakan database
